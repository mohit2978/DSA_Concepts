## Q1. Same Tree (LeetCode 100)

**Problem:** Given the roots of two binary trees `p` and `q`, write a function to check if they are the same or not.

Two binary trees are considered the same if they are structurally identical, and the nodes have the same value.

**Example 1:**
```
Input: p = [1,2,3], q = [1,2,3]
Output: true
```

**Example 2:**
```
Input: p = [1,2], q = [1,null,2]
Output: false
```

**Example 3:**
```
Input: p = [1,2,1], q = [1,1,2]
Output: false
```

**Constraints:**
- The number of nodes in both trees is in the range `[0, 100]`.
- `-10^4 <= Node.val <= 10^4`

**Approach:** Recursively check three things at every pair of nodes: both null (match), only one null (mismatch), or both non-null with equal values — then recurse into the left pair and the right pair, combining all three results with AND.



```java

class Solution {
    public boolean isSameTree(TreeNode p, TreeNode q) {
        if(p==null&&q==null) return true;
        if(p!=null&&q==null) return false;
        if(p==null&&q!=null) return false;
        
        boolean lres=isSameTree(p.left,q.left);
        boolean rres=isSameTree(p.right,q.right);
        
        boolean myres=(p.val==q.val);
        return lres&&rres&&myres;
        
    }
}
```

**C++** (same logic, added since only Java existed):
```cpp
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        if (p == nullptr && q == nullptr) return true;
        if (p != nullptr && q == nullptr) return false;
        if (p == nullptr && q != nullptr) return false;

        bool lres = isSameTree(p->left, q->left);
        bool rres = isSameTree(p->right, q->right);

        bool myres = (p->val == q->val);
        return lres && rres && myres;
    }
};
```

**Dry run** on `p = [1,2,3]`, `q = [1,2,3]`: at the root, neither is null, so recurse — left pair `(2,2)`: values match, both children null → `true`; right pair `(3,3)`: same → `true`; root's own values `1==1` → `true`. Combined: `true && true && true = true`, matching the expected output.

**Time Complexity: `O(n)`**, where `n` is the number of nodes in the smaller tree — every node pair is visited at most once, and the moment a mismatch or a null/non-null mismatch is found, that branch returns immediately.
**Space Complexity: `O(h)`** for the recursion stack, where `h` is the height of the tree (worst case `O(n)` for a skewed tree).

## Q2. Binary Tree Level Order Traversal II (LeetCode 107)

**Problem:** Given the `root` of a binary tree, return *the bottom-up level order traversal of its nodes' values*. (i.e., from left to right, level by level from leaf to root).

**Example 1:**
```
Input: root = [3,9,20,null,null,15,7]
Output: [[15,7],[9,20],[3]]
```

**Example 2:**
```
Input: root = [1]
Output: [[1]]
```

**Example 3:**
```
Input: root = []
Output: []
```

**Constraints:**
- The number of nodes in the tree is in the range `[0, 2000]`.
- `-1000 <= Node.val <= 1000`

**Approach:** This is a standard BFS-based level order traversal — process the tree one level at a time using a queue, collecting each level into its own list — with one twist: since the problem wants the levels ordered bottom-to-top instead of top-to-bottom, simply reverse the final list of levels at the end.

There are two general strategies to traverse a tree: **Depth First Search (DFS)** — go all the way down to a leaf before backtracking to explore another branch (further split into preorder, inorder, postorder) — and **Breadth First Search (BFS)** — scan level by level, top to bottom, visiting every node on a higher level before any node on a lower level. Level-order traversal is the classic BFS use case, typically implemented with a queue.


 

```java

class Solution {
    public List<List<Integer>> levelOrderBottom(TreeNode root) {
        List<List<Integer>> res = new ArrayList<List<Integer>>();
        if (root == null) return res;
        LinkedList <TreeNode>q=new LinkedList<>();
        q.addLast(root);
        while(q.size()>0){
            List<Integer>temp=new ArrayList<>();
            int sz=q.size();
            while(sz-->0){
                TreeNode fr=q.removeFirst();
                temp.add(fr.val);
                if(fr.left!=null)
                    q.addLast(fr.left);
                if(fr.right!=null)
                    q.addLast(fr.right);
            }
        res.add(temp);    
        }
        Collections.reverse(res);
        return res;
        
    }
}
```

**C++** (same logic, added since only Java existed):
```cpp
class Solution {
public:
    vector<vector<int>> levelOrderBottom(TreeNode* root) {
        vector<vector<int>> res;
        if (root == nullptr) return res;
        deque<TreeNode*> q;
        q.push_back(root);
        while (q.size() > 0) {
            vector<int> temp;
            int sz = q.size();
            while (sz-- > 0) {
                TreeNode* fr = q.front();
                q.pop_front();
                temp.push_back(fr->val);
                if (fr->left != nullptr)
                    q.push_back(fr->left);
                if (fr->right != nullptr)
                    q.push_back(fr->right);
            }
            res.push_back(temp);
        }
        reverse(res.begin(), res.end());
        return res;
    }
};
```

**Dry run** on `root = [3,9,20,null,null,15,7]`: level-by-level BFS gives `[[3], [9,20], [15,7]]`, then reversing gives **`[[15,7],[9,20],[3]]`** — matching the expected output.

**Time Complexity: `O(n)`** — every node is enqueued and dequeued exactly once. **Space Complexity: `O(w)`** for the queue (`w` = maximum width of the tree, `O(n)` worst case), plus `O(n)` for the output.

## Q3. Binary Tree Level Order Traversal (LeetCode 102)

A closely related companion question — this is the same traversal as Q2, minus the final reversal, since here the levels are wanted top-to-bottom instead of bottom-to-top.

**Problem:** Given the `root` of a binary tree, return *the level order traversal of its nodes' values* (i.e., from left to right, level by level).

**Java** (the same BFS approach as Q2, with the `Collections.reverse` line removed):
```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> res = new ArrayList<List<Integer>>();
        if (root == null) return res;
        LinkedList<TreeNode> q = new LinkedList<>();
        q.addLast(root);
        while (q.size() > 0) {
            List<Integer> temp = new ArrayList<>();
            int sz = q.size();
            while (sz-- > 0) {
                TreeNode fr = q.removeFirst();
                temp.add(fr.val);
                if (fr.left != null)
                    q.addLast(fr.left);
                if (fr.right != null)
                    q.addLast(fr.right);
            }
            res.add(temp);
        }
        return res;
    }
}
```

**C++:**
```cpp

```

**Approach 2 — Recursive (DFS-based), LeetCode's official alternative:** instead of a queue, recurse through the tree while tracking the current `level`; the first time a given level is reached, start a new list for it, then append the current node's value to that level's list, and recurse into both children at `level + 1`.

**Java:**
```java
class Solution {
    List<List<Integer>> levels = new ArrayList<List<Integer>>();

    public void helper(TreeNode node, int level) {
        // start the current level
        if (levels.size() == level)
            levels.add(new ArrayList<Integer>());

        // fulfil the current level
        levels.get(level).add(node.val);

        // process child nodes for the next level
        if (node.left != null)
            helper(node.left, level + 1);
        if (node.right != null)
            helper(node.right, level + 1);
    }

    public List<List<Integer>> levelOrder(TreeNode root) {
        if (root == null) return levels;
        helper(root, 0);
        return levels;
    }
}
```

**C++:**
```cpp
class Solution {
    vector<vector<int>> levels;

    void helper(TreeNode* node, int level) {

        levels[level].push_back(node->val);

            helper(node->right, level + 1);

    vector<vector<int>> levelOrder(TreeNode* root) {

        helper(root, 0);
        return levels;
    }
};
```

**Time Complexity: `O(n)`** for both approaches — every node visited once. **Space Complexity: `O(n)`** for the output plus `O(w)` (BFS queue) or `O(h)` (DFS recursion stack) auxiliary space.

```java
class Solution {
    public class pair {
        int ht = -1;
        boolean isbal = true;
    }

    public pair helper(TreeNode root) {
        if (root == null) {
            pair bc = new pair();
            return bc;
        }
        pair lres = helper(root.left);
        pair rres = helper(root.right);
        pair res = new pair();

        boolean factor = Math.abs(lres.ht - rres.ht) <= 1;
        res.ht = Math.max(lres.ht, rres.ht) + 1;
        res.isbal = lres.isbal && rres.isbal && factor;
        return res;
    }

    public boolean isBalanced(TreeNode root) {
        if (root == null || (root.left == null && root.right == null))
            return true;
        pair res = helper(root);
        return res.isbal;
    }
}
```

## Q5. Maximum Depth of Binary Tree (LeetCode 104)

**Problem:** Given the `root` of a binary tree, return *its maximum depth*.

A binary tree's **maximum depth** is the number of nodes along the longest path from the root node down to the farthest leaf node.

**Example 1:**
```
Input: root = [3,9,20,null,null,15,7]
Output: 3
```

**Approach:** This question asks about height according to node — the base case is `if (node == null) return 0;`. Otherwise, recursively find the max depth of the left and right subtrees and return `1 + max(leftDepth, rightDepth)`.

**Java:**
```java
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        int lres = maxDepth(root.left);
        int rres = maxDepth(root.right);
        return Math.max(lres, rres) + 1;
    }
}
```

**C++:**
```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) return 0;
        int lres = maxDepth(root->left);
        int rres = maxDepth(root->right);
        return max(lres, rres) + 1;
    }
};
```

**Dry run** on `root = [3,9,20,null,null,15,7]`: `maxDepth(9)=1`, `maxDepth(15)=1`, `maxDepth(7)=1`, `maxDepth(20)=max(1,1)+1=2`, `maxDepth(3)=max(1,2)+1=3` — matching the expected output.

**Time Complexity: `O(n)`** — every node visited once. **Space Complexity: `O(h)`** for the recursion stack.

## Q6. Minimum Depth of Binary Tree (LeetCode 111)

**Problem:** Given a binary tree, find its minimum depth.

The minimum depth is the number of nodes along the shortest path from the root node down to the nearest leaf node.

**Note:** A leaf is a node with no children.

**Example 1:**
```
Input: root = [3,9,20,null,null,15,7]
Output: 2
```

**Example 2:**
```
Input: root = [2,null,3,null,4,null,5,null,6]
Output: 5
```

**Constraints:**
- The number of nodes in the tree is in the range `[0, 10^5]`.
- `-1000 <= Node.val <= 1000`

**A common first-attempt bug:** it's tempting to write this as a direct mirror of Maximum Depth, just swapping `max` for `min`:
```java
// WRONG
public int minDepth(TreeNode root) {
    if (root == null) return 0;
    if (root.left == null && root.right == null) return 1;
    int lres = minDepth(root.left);
    int rres = minDepth(root.right);
    return Math.min(lres, rres) + 1;
}
```
This fails on `root = [2,null,3,null,4,null,5,null,6]` (a right-skewed chain, expected `5`) — it returns `1`. The bug: whenever a node has only **one** child (the other is `null`), `minDepth(null)` returns `0` from the base case, and `Math.min(0, anything) + 1` always evaluates to `1`, regardless of how deep the real (non-null) side actually goes. A missing child isn't a valid "path to a leaf" and must not be allowed to win the `min`.

**The fix:** substitute `Integer.MAX_VALUE` for whichever side is `null`, so the `min` correctly ignores it (the true leaf base case above already handles the case where *both* sides are null):

**Java:**
```java
class Solution {
    public int minDepth(TreeNode root) {
        if (root == null) return 0;
        if (root.left == null && root.right == null) return 1;
        int lres = minDepth(root.left);
        int rres = minDepth(root.right);
        return Math.min(
            (root.left == null ? Integer.MAX_VALUE : lres),
            (root.right == null ? Integer.MAX_VALUE : rres)
        ) + 1;
    }
}
```

**C++:**
```cpp
class Solution {
public:
    int minDepth(TreeNode* root) {
        if (root == nullptr) return 0;
        if (root->left == nullptr && root->right == nullptr) return 1;
        int lres = minDepth(root->left);
        int rres = minDepth(root->right);
        return min(
            (root->left == nullptr ? INT_MAX : lres),
            (root->right == nullptr ? INT_MAX : rres)
        ) + 1;
    }
};
```

**Dry run** on `[2,null,3,null,4,null,5,null,6]` (a chain `2→3→4→5→6`, each having only a right child except the true leaf `6`):
`minDepth(6)=1` (leaf). `minDepth(5)`: left is null → `min(MAX, 1)+1 = 2`. `minDepth(4)`: `min(MAX, 2)+1 = 3`. `minDepth(3)`: `min(MAX, 3)+1 = 4`. `minDepth(2)`: `min(MAX, 4)+1 = 5` — matching the expected output.

**A cleaner equivalent, and a faster BFS alternative:** LeetCode's own solution writes the DFS slightly more directly (checking each null child individually rather than substituting `MAX_VALUE`), which is exactly equivalent:
```cpp
int minDepthDFS(TreeNode* root) {
    if (root == nullptr) return 0;
    if (root->left == nullptr) return minDepth(root->right) + 1;
    if (root->right == nullptr) return minDepth(root->left) + 1;
    return min(minDepth(root->left), minDepth(root->right)) + 1;
}
```
DFS visits every node before it can be sure it's found the true minimum, since the shortest path could be discovered late in the traversal. **BFS is a genuinely better fit for this specific problem** (unlike Maximum Depth, where BFS offers no advantage): since BFS explores level by level, the very first leaf encountered is guaranteed to be at the minimum depth, so the search can stop immediately instead of exploring the rest of the tree.

```cpp
int minDepthBFS(TreeNode* root) {
    if (root == nullptr) return 0;

    int depth = 0;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty())
    {
        depth++;
        int n = q.size();
        for (int i = 0; i < n; i++)
        {
            TreeNode* p = q.front(); q.pop();
            if (!p->left && !p->right) return depth;

            if (p->left) q.push(p->left);
            if (p->right) q.push(p->right);
        }
    }
    return depth;
}
```

**Time Complexity:** DFS: `O(n)` worst case (a tree with no early leaf must still be fully explored). BFS: `O(n)` worst case too, but with the practical advantage of stopping the moment the first (shallowest) leaf is found.
**Space Complexity: `O(h)`** for DFS's recursion stack (`O(log n)` best case for a balanced tree, `O(n)` worst case for a skewed one); `O(w)` for BFS's queue (`w` = max width of the tree).

## Q7. Cousins in Binary Tree (LeetCode 993)

**Problem:** Given the `root` of a binary tree with unique values and the values of two different nodes of the tree `x` and `y`, return `true` if the nodes corresponding to the values `x` and `y` in the tree are **cousins**, or `false` otherwise.

Two nodes of a binary tree are **cousins** if they have the same depth with different parents.

Note that in a binary tree, the root node is at the depth `0`, and children of each depth `k` node are at the depth `k + 1`.


**Example 1:**
```
Input: root = [1,2,3,null,4,null,5], x = 5, y = 4
Output: true
```

**Example 2:**
```
Input: root = [1,2,3,null,4], x = 2, y = 3
Output: false
```

**Example 3:**
```
Input: root = [1,2,3,null,4,null,5], x = 2, y = 3
Output: false
```

**Constraints:**
- The number of nodes in the tree will be in the range `[2, 100]`.
- `1 <= Node.val <= 100`
- Each node has a **unique** value.
- `x != y`
- `x` and `y` are exist in the tree.

**Approach:** Do a level-order (BFS) traversal, but track each node together with its **parent's value** (using a small `nodepair` helper class). Process one whole level at a time: within a level, look for the node whose value is `x` and the node whose value is `y`. If both are found within the *same* level, they're at the same depth — the answer is simply whether their recorded parent values differ.


**Dry run** on `root = [1,2,3,null,4,null,5]`, `x = 5`, `y = 4` (tree: `1(2(_,4), 3(_,5))`):
- Level 0: `(1, parent=-1)`. Neither matches `x` or `y`. Push `(2, parent=1)` and `(3, parent=1)`.
- Level 1: `(2, parent=1)`, `(3, parent=1)`. Neither matches. Push `(4, parent=2)` (right child of `2`) and `(5, parent=3)` (right child of `3`).
- Level 2: `(4, parent=2)` matches `y=4` → record `ychck = (4, par=2)`. `(5, parent=3)` matches `x=5` → record `xchck = (5, par=3)`; since `ychck` was already found this level, immediately return `ychck.par != xchck.par` → `2 != 3` → **`true`**.




 
 ```java

class Solution {
    public class nodepair{
        TreeNode child;
        int par;
        nodepair(){
            par=-1;
            }
        nodepair(TreeNode child,int par){
            this.child=child;
            this.par=par;
        }
    }
    public boolean isCousins(TreeNode root, int x, int y) {
         LinkedList <nodepair>q=new LinkedList<>();
        nodepair rt=new nodepair(root,-1);
        q.addLast(rt);
        while(q.size()>0){
            int sz=q.size();
            nodepair xchck=new nodepair();
            nodepair ychck=new nodepair();
            while(sz-->0)
            {
                nodepair fr=q.removeFirst();
                if(fr.child!=null&&fr.child.val==x){
                    xchck.child=fr.child;
                    xchck.par=fr.par;
                    if(ychck.par!=-1){
                       return ychck.par!=xchck.par;
                    }
                }
                if(fr.child!=null&&fr.child.val==y){
                    ychck.child=fr.child;
                    ychck.par=fr.par;
                    if(xchck.par!=-1){
                       return ychck.par!=xchck.par;
                    }
                }
                if(fr.child!=null&&fr.child.left!=null){
                    nodepair lc=new nodepair(fr.child.left,fr.child.val);
                    q.addLast(lc);
                }
                    
                if(fr.child!=null&&fr.child.right!=null)
                { nodepair rc=new nodepair(fr.child.right,fr.child.val);
                    q.addLast(rc);
                    
                }
                
            }

        }
        return false;
    }
}
```
 
**C++** (same logic, added since only Java existed):
```cpp
class Solution {
    struct nodepair {
        TreeNode* child;
        int par;
        nodepair() : child(nullptr), par(-1) {}
        nodepair(TreeNode* child, int par) : child(child), par(par) {}
    };

public:
    bool isCousins(TreeNode* root, int x, int y) {
        deque<nodepair> q;
        nodepair rt(root, -1);
        q.push_back(rt);
        while (q.size() > 0) {
            int sz = q.size();
            nodepair xchck;
            nodepair ychck;
            while (sz-- > 0) {
                nodepair fr = q.front();
                q.pop_front();
                if (fr.child != nullptr && fr.child->val == x) {
                    xchck.child = fr.child;
                    xchck.par = fr.par;
                    if (ychck.par != -1) {
                        return ychck.par != xchck.par;
                    }
                }
                if (fr.child != nullptr && fr.child->val == y) {
                    ychck.child = fr.child;
                    ychck.par = fr.par;
                    if (xchck.par != -1) {
                        return ychck.par != xchck.par;
                    }
                }
                if (fr.child != nullptr && fr.child->left != nullptr) {
                    nodepair lc(fr.child->left, fr.child->val);
                    q.push_back(lc);
                }
                if (fr.child != nullptr && fr.child->right != nullptr) {
                    nodepair rc(fr.child->right, fr.child->val);
                    q.push_back(rc);
                }
            }
        }
        return false;
    }
};
```

**Time Complexity: `O(n)`** — every node is enqueued/dequeued once, and the search returns as soon as both `x` and `y` are found in the same level. **Space Complexity: `O(w)`** for the queue (`w` = maximum width of the tree, `O(n)` worst case).

## Q8. Symmetric Tree (LeetCode 101)

**Problem:** Given the `root` of a binary tree, check whether it is a mirror of itself (i.e., symmetric around its center).

**Constraints:**
- The number of nodes in the tree is in the range `[1, 1000]`.
- `-100 <= Node.val <= 100`

**Approach:** A tree is symmetric if its left subtree is a mirror reflection of its right subtree. Two subtrees are mirrors of each other if their root values are equal, and each subtree's left is a mirror of the other's right (and vice versa).

**Java** (official LeetCode-style solution — clean and compact):
```java
class Solution {
    public boolean isSymmetric(TreeNode root) {
        return isMirror(root, root);
    }

    public boolean isMirror(TreeNode t1, TreeNode t2) {
        if (t1 == null && t2 == null) return true;
        if (t1 == null || t2 == null) return false;
        return (t1.val == t2.val)
            && isMirror(t1.right, t2.left)
            && isMirror(t1.left, t2.right);
    }
}
```

**C++:**

**A more verbose, but equally correct, first-attempt style** (spelling out every null/value comparison individually rather than folding them into the single `||` check above) — kept here since it's a natural way to first arrive at the solution, even though it ends up considerably longer:
```java
class Solution {
    public boolean ismirror(TreeNode r1, TreeNode r2) {
        if (r1 == null && r2 == null) return true;
        if (r1 != null && r2 == null) return false;
        if (r1 == null && r2 != null) return false;
        if (r1.right == null && r2.left != null) return false;
        if (r1.right != null && r2.left == null) return false;
        if (r1.right != null && r2.left != null && r1.right.val != r2.left.val)
            return false;
        if (r1.left != null && r2.right == null) return false;
        if (r1.left == null && r2.right != null) return false;
        if (r1.left != null && r2.right != null && r1.left.val != r2.right.val)
            return false;

        boolean lres = ismirror(r1.left, r2.right);
        boolean rres = ismirror(r1.right, r2.left);
        return lres & rres;
    }

    public boolean isSymmetric(TreeNode root) {
        return ismirror(root, root);
    }
}
```
All of those individual null/value checks above are exactly what the official solution's single line `if (t1 == null || t2 == null) return false;` plus `t1.val == t2.val` accomplish in two lines instead of nine — the two are logically equivalent, just expressed at different levels of compactness. Also note there's no need to separately handle "is the root itself symmetric" as a special case: calling `isMirror(root, root)` always trivially matches on the first call (a node compared with itself), so the recursion correctly falls through to comparing the actual children.

**Time Complexity: `O(n)`** — every node pair is visited once. **Space Complexity: `O(h)`** for the recursion stack.

## Q9. Path Sum (LeetCode 112)

**Problem:** Given the `root` of a binary tree and an integer `targetSum`, return `true` if the tree has a **root-to-leaf** path such that adding up all the values along the path equals `targetSum`.

A **leaf** is a node with no children.

**Example 1:**
```
Input: root = [5,4,8,11,null,13,4,7,2,null,null,null,1], targetSum = 22
Output: true
Explanation: The root-to-leaf path with the target sum is shown (5 -> 4 -> 11 -> 2, summing to 22).
```

**Example 2:**
```
Input: root = [1,2,3], targetSum = 5
Output: false
```

**Example 3:**
```
Input: root = [], targetSum = 0
Output: false
```

**Constraints:**
- The number of nodes in the tree is in the range `[0, 5000]`.
- `-1000 <= Node.val <= 1000`
- `-1000 <= targetSum <= 1000`

Given an empty input (`root = []`), the output should be `false`, since there's no path at all to sum up.

**Approach:** Recursively subtract the current node's value from the target as we descend; at a leaf, check whether the remaining target has hit exactly `0`.

**Java** (self-written style — explicit leaf check, explicit left/right recursion with early return):
```java
class Solution {
    public boolean hasPathSum(TreeNode root, int targetSum) {
        if (root == null) {
            return false;
        }
        if (root.left == null && root.right == null) {
            if (targetSum - root.val == 0) return true;
            return false;
        }
        boolean lres = hasPathSum(root.left, targetSum - root.val);
        if (lres == true) return true;
        boolean rres = hasPathSum(root.right, targetSum - root.val);
        if (rres == true) return true;

        return false;
    }
}
```

**C++:**

**A more compact equivalent** (LeetCode's own solution style — mutating the running sum in place with `||` short-circuiting instead of separate boolean variables):
```java
class Solution {
    public boolean hasPathSum(TreeNode root, int sum) {
        if (root == null)
            return false;

        sum -= root.val;
        if ((root.left == null) && (root.right == null))
            return (sum == 0);
        return hasPathSum(root.left, sum) || hasPathSum(root.right, sum);
    }
}
```

**Time Complexity: `O(n)`** — every node is visited at most once (with early termination the moment a valid path is found). **Space Complexity: `O(h)`** for the recursion stack.

## Q10. Maximum Difference Between Node and Ancestor (LeetCode 1026)

**Problem:** Given the `root` of a binary tree, find the maximum value `v` for which there exist **different** nodes `a` and `b` where `v = |a.val - b.val|` and `a` is an ancestor of `b`.

A node `a` is an ancestor of `b` if either: any child of `a` is equal to `b` or any child of `a` is an ancestor of `b`.

**Example 1:**
```
Input: root = [8,3,10,1,6,null,14,null,null,4,7,13]
Output: 7
Explanation: We have various ancestor-node differences, some of which are given below :
|8 - 3| = 5
|3 - 7| = 4
|8 - 1| = 7
|10 - 13| = 3
Among all possible differences, the maximum value of 7 is obtained by |8 - 1| = 7.
```

**Example 2:**
```
Input: root = [1,null,2,null,0,3]
Output: 3
```

**Constraints:**
- The number of nodes in the tree is in the range `[2, 5000]`.
- `0 <= Node.val <= 10^5`

**Approach:** For each node, pass down the minimum and maximum values seen so far *among its ancestors* (not including itself yet). At every node, compute the difference between the current node's value and both the running min and the running max — one of these two will be the largest possible ancestor-difference involving this node — then update `res` with whichever is larger. Only *after* using the ancestor min/max is the current node's own value folded into the min/max that gets passed further down.

**Dry run** on `root = [8,3,10,1,6,null,14,null,null,4,7,13]`:
- At `8` (root): `mn = 8`, `mx = 8` (no ancestors yet, so initialize from the root itself).
- At `3` (left child of `8`): `t1 = |8-3| = 5`, `t2 = |8-3| = 5`, `res = 5`. Update `mn = min(8,3) = 3`, `mx = max(8,3) = 8`.
- At `1` (left child of `3`): `t1 = |3-1| = 2`, `t2 = |8-1| = 7`, `res = max(5, 7) = 7`. Update `mn = 1`, `mx = 8`.
- ...continuing through the rest of the tree, no other pair produces a difference greater than `7`.

**Final answer: 7** — matching the expected output exactly.

**Java:**
```java
class Solution {
    int res = (int) -1e6;

    private void helper(TreeNode root, int mn, int mx) {
        if (root == null) return;
        int t1 = Math.abs(mn - root.val);
        int t2 = Math.abs(mx - root.val);
        res = Math.max(t1, Math.max(t2, res));
        mn = Math.min(mn, root.val);
        mx = Math.max(mx, root.val);
        helper(root.left, mn, mx);
        helper(root.right, mn, mx);
    }

    public int maxAncestorDiff(TreeNode root) {
        int mn = root.val;
        int mx = root.val;
        helper(root, mn, mx);
        return res;
    }
}
```


**C++** (same logic, added since only Java existed):

**Time Complexity: `O(n)`** — every node visited once. **Space Complexity: `O(h)`** for the recursion stack, where `h` is the height of the tree.

### Approach 2 — return the difference directly instead of using a class-level result field

A cleaner variant of the exact same idea: instead of maintaining a `res` field that gets updated as a side effect, have the base case (`root == nullptr`) directly return `maxVal - minVal` for whatever ancestor min/max was passed down to it, and bubble up the maximum of the left and right subtrees' results through the return value alone.

**C++:**
```cpp
class Solution {
public:
    int maxDiff(TreeNode* node, int maxVal, int minVal) {
        if (node == nullptr) return maxVal - minVal;

        maxVal = max(maxVal, node->val);
        minVal = min(minVal, node->val);
        int maxLeftDiff = maxDiff(node->left, maxVal, minVal);
        int maxRightDiff = maxDiff(node->right, maxVal, minVal);

        return max(maxLeftDiff, maxRightDiff);
    }

    int maxAncestorDiff(TreeNode* root) {
        if (root == nullptr) return 0;
        return maxDiff(root, root->val, root->val);
    }
};
```

**Java:**
```java
class Solution {
    public int maxDiff(TreeNode node, int maxVal, int minVal) {
        if (node == null) return maxVal - minVal;

        maxVal = Math.max(maxVal, node.val);
        minVal = Math.min(minVal, node.val);
        int maxLeftDiff = maxDiff(node.left, maxVal, minVal);
        int maxRightDiff = maxDiff(node.right, maxVal, minVal);

        return Math.max(maxLeftDiff, maxRightDiff);
    }

    public int maxAncestorDiff(TreeNode root) {
        if (root == null) return 0;
        return maxDiff(root, root.val, root.val);
    }
}
```

**Dry run** on the same tree `[8,3,10,1,6,null,14,null,null,4,7,13]`, tracing just the left spine: `maxDiff(8, 8, 8)` → update `maxVal=8, minVal=8` → recurse left into `3` with `(8,8)`. `maxDiff(3, 8, 8)` → update `maxVal=8, minVal=3` → recurse left into `1` with `(8,3)`. `maxDiff(1, 8, 3)` → update `maxVal=8, minVal=1` → both children are `null`, so both recursive calls return `8 - 1 = 7`. That `7` bubbles all the way back up through `max(...)` calls at every level, ending up as the final answer — matching the expected output.

**Time Complexity: `O(n)`. Space Complexity: `O(h)`** — same reasoning as Approach 1; this version simply avoids the class-level mutable field in favor of passing the result back up through return values, which is a matter of style rather than efficiency.





## Q11. LC 2196. Create Binary Tree From Descriptions


### **Problem Statement**

You are given a 2D integer array `descriptions` where `descriptions[i] = [parent_i, child_i, isLeft_i]` indicates that `parent_i` is the parent of `child_i` in a binary tree of unique values. Furthermore:

* If `isLeft_i == 1`, then `child_i` is the left child of `parent_i`.
* If `isLeft_i == 0`, then `child_i` is the right child of `parent_i`.

Construct the binary tree described by `descriptions` and return its root.

*The test cases will be generated such that the binary tree is valid.*

---

### **Examples**

**Example 1:**

* **Input:** `descriptions = [[20,15,1], [20,17,0], [50,20,1], [50,80,0], [80,19,1]]`
* **Output:** `[50,20,80,15,17,19]`
* **Explanation:** The root node is the node with value 50 since it has no parent.

**Example 2:**

* **Input:** `descriptions = [[1,2,1], [2,3,0], [3,4,1]]`
* **Output:** `[1,2,null,null,3,4]`
* **Explanation:** The root node is the node with value 1 since it has no parent.

---

### **Constraints:**

* `1 <= descriptions.length <= 10^4`
* `descriptions[i].length == 3`
* `1 <= parent_i, child_i <= 10^5`
* `0 <= isLeft_i <= 1`
* The binary tree described by `descriptions` is guaranteed to be valid.


```cpp

class Solution {
    unordered_map<int, TreeNode*> adressMp;
    unordered_map<TreeNode*, bool> parMap;
    TreeNode* helper(vector<vector<int>>& arr) {
        for (auto vec : arr) {
            int par = vec[0];
            int child = vec[1];
            int isLeft = vec[2];
            TreeNode* parNode = nullptr;
            TreeNode* childNode = nullptr;
            if (adressMp.find(par) == adressMp.end()) {
                parNode = new TreeNode(par);
                adressMp[par] = parNode;
            } else
                parNode = adressMp[par];

            if (adressMp.find(child) == adressMp.end()) {
                childNode = new TreeNode(child);
                adressMp[child] = childNode;
            } else
                childNode = adressMp[child];
            parMap[childNode] = false;
            if (parMap.find(parNode) == parMap.end())
                parMap[parNode] = true;
            if (isLeft == 1)
                parNode->left = childNode;
            else
                parNode->right = childNode;
        }
        TreeNode* root = nullptr;
        for (auto p : parMap) {
            if (p.second == true) {
                root = p.first;
                break;
            }
        }
        return root;
    }

public:
    TreeNode* createBinaryTree(vector<vector<int>>& descriptions) {
        return helper(descriptions);
    }
};
```

**Java** (same logic, added since only C++ existed):
```java
class Solution {
    HashMap<Integer, TreeNode> addressMp = new HashMap<>();
    HashMap<TreeNode, Boolean> parMap = new HashMap<>();

    private TreeNode helper(int[][] arr) {
        for (int[] vec : arr) {
            int par = vec[0];
            int child = vec[1];
            int isLeft = vec[2];
            TreeNode parNode;
            TreeNode childNode;
            if (!addressMp.containsKey(par)) {
                parNode = new TreeNode(par);
                addressMp.put(par, parNode);
            } else {
                parNode = addressMp.get(par);
            }

            if (!addressMp.containsKey(child)) {
                childNode = new TreeNode(child);
                addressMp.put(child, childNode);
            } else {
                childNode = addressMp.get(child);
            }
            parMap.put(childNode, false);
            if (!parMap.containsKey(parNode)) {
                parMap.put(parNode, true);
            }
            if (isLeft == 1) {
                parNode.left = childNode;
            } else {
                parNode.right = childNode;
            }
        }
        TreeNode root = null;
        for (Map.Entry<TreeNode, Boolean> p : parMap.entrySet()) {
            if (p.getValue() == true) {
                root = p.getKey();
                break;
            }
        }
        return root;
    }

    public TreeNode createBinaryTree(int[][] descriptions) {
        return helper(descriptions);
    }
}
```

**Dry run** on `descriptions = [[20,15,1], [20,17,0], [50,20,1], [50,80,0], [80,19,1]]`: processing each description creates/looks up the parent and child nodes via `addressMp` (so the same value always maps to the same `TreeNode` object no matter how many times it appears), wires up `.left`/`.right` per `isLeft`, and marks every value that appears as a `child` as `false` in `parMap` (since it now has a parent) while any value seen as a `parent` gets `true` unless it's already been downgraded to `false` by appearing as someone's child. After processing all five descriptions, `50` is the only value that never appeared as a `child`, so it's identified as the root — matching the expected output `[50,20,80,15,17,19]`.

**Time Complexity: `O(n)`**, where `n` is the number of descriptions — each description does a constant number of `O(1)` average-case hash map operations. **Space Complexity: `O(n)`** — for the two hash maps, which together hold one entry per distinct node value.
